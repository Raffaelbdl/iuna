# Evaluating Language Learning

## Overview

**Core principle:** In languages, the proof of understanding is production — generating novel, correct output — plus retention over time. Recognition (MCQs) is only the calibration signal; a learner can pass every recognition check and be unable to produce a sentence.

| Tier | Attached to | Form | Example (Japanese, teaching て-form) |
|---|---|---|---|
| **Check** | one node | recognition MCQ, in-flow | "Which is the て-form of 飲む?" |
| **Challenge 🏋️** | a completed cluster | produce novel output using the cluster | "Write 3 sentences asking permission, using verbs I give you — verbs you haven't seen conjugated in this lesson" |
| **Project 📦** | a milestone | free production between sessions | "Write a short diary entry about your week using て-form requests, permissions, and prohibitions" |

## Designing Challenges (during Plan phase)

- Production challenges use **unseen instances of the taught pattern** — new verbs for a conjugation rule, new contexts for a grammar point. Reproducing the lesson's own examples tests memory of the page, not the rule.
- Direction matters: L1→L2 production is the hard, honest direction. Prefer it for challenges; L2→L1 comprehension belongs in checks.
- Milestone projects favor **free production in context** (diary entry, dialogue, message you'd actually send) over drill batteries — context forces retrieval the way real use does.
- **Retention is part of the DAG:** unlike code, language knowledge decays. When planning a session, schedule brief revisits of clusters from previous sessions (expanding intervals). A cluster is not "solid" in the map until it has survived at least one delayed revisit.

## Grading

1. **Separate the layers:** does the sentence make the target error (the pattern being taught), an old-pattern error (previously-solid cluster — a decay signal: mark it for revisit), or an out-of-scope error (a pattern not yet taught)?
2. **Out-of-scope errors are not failures.** Note them at most briefly, or silently — grading a learner on what was never taught poisons trust and drowns signal. If one recurs, it's evidence for a new node in the DAG, not a red mark.
3. **Classify in-scope errors** with the tutor's error ladder (slip / current-node gap / prerequisite gap) and respond per the ladder — point at the error's location or rule, never hand back the corrected sentence.
4. **Naturalness comes after correctness.** Only flag unnatural-but-grammatical phrasing once the target pattern is solid, and frame it as an upgrade, not an error.

## Rationalizations

| Excuse | Reality |
|--------|---------|
| "They aced the MCQs, production would be redundant" | Recognition and production are different memories. Every cluster ends in production. |
| "I'll reuse the lesson's examples in the challenge" | That tests memory of the page. New instances or it isn't a test. |
| "I'll correct every mistake in their paragraph" | Correcting out-of-scope errors drowns the signal. Grade the target pattern; log the rest. |
| "The cluster was solid last week, no need to revisit" | Language decays. Solid means survived a delayed revisit, not passed once. |
| "I'll just give the natural phrasing" | Handing back the corrected sentence is stealing struggle. Point at the rule, let them redo. |
| "They picked the natural verb — I'll praise their strategic choice" | Verify before attributing intent. If the learner answered on reflex (反射的に) and says so, credit it honestly: reflexive-correct output is intuition data — valuable, but different from deliberate mastery. Flattering misattribution gets called out and burns trust; diagnose the response itself. |
